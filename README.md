# 외환 한 시간

[휴대폰에서 공부하기](https://ju3102-ui.github.io/fx-ox/)

외환전문역 1종을 하루 한 시간씩 공부하기 위한 O/X 학습 웹페이지입니다. 한국금융연수원 공식 교재 목차를 기준으로 총론부터 세 과목의 마지막 단원까지 한 흐름으로 구성했습니다.

## 학습 구성

| 과목 | 단원 | 문항 |
| --- | ---: | ---: |
| 외환관리실무 | 12 | 150 |
| 외국환거래실무 | 6 | 90 |
| 환리스크관리 | 6 | 60 |
| 합계 | 24 | 300 |

외환관리실무 1장 총론은 49문항입니다. 법의 목적·법령 체계, 적용범위, 용어, 거주성, 취급기관, 비상조치와 외국환평형기금 순으로 공부합니다. 후속 단원에서 은행·전문업자, 지급·상계, 자본거래, 현지금융, 직접투자, 보고·검사, 외국인투자와 대외무역을 다룹니다.

거래실무는 환거래·외화자금·송금·수표 외에 특수상품, 회계, 컴플라이언스, 위규사례를 보완했습니다. 환리스크관리는 외환시장·관리절차부터 선물환, 선물, 스왑, 옵션으로 연결합니다. 교재의 모든 세부 항목을 대체하거나 출제빈도를 보장하는 자료는 아닙니다.

## 사용법

- **학습**: ‘이어서 공부하기’로 교재 순서대로 최대 34문항씩 풉니다. 완료 후 다음 묶음으로 바로 이어집니다.
- **목차**: 원하는 과목·단원을 선택하여 처음 문제부터 복습합니다. 단원 완료 후 다음 단원으로 이어갈 수 있습니다.
- **오답**: 최근에 틀린 문제와 ★ 표시를 모읍니다. 다시 맞히면 오답에서 빠지고 ★는 직접 해제합니다.
- **자료**: 핵심요약, 출처, 백업·불러오기를 제공합니다.

11월 11~19일은 하루 약 34문항, 11월 20일은 오답 복습을 권합니다. 한 시간은 이전 오답 10분, 새 문제·해설 40분, 틀린 문장 고쳐 말하기 10분으로 나눕니다. 진도는 날짜 때문에 건너뛰지 않습니다.

## 자료의 성격과 기준일

공식 공개 샘플 15문항에서 연결한 **74문항**, 자체 예상·기본 **226문항**입니다. 실제 회차별 기출 원문은 확보하지 못했습니다. ‘샘플 연계’는 같은 수의 실제 기출을 확보했다는 의미가 아닙니다. 문장·해설은 학습용으로 새로 작성했고 공식 샘플 원본 PDF는 재게시하지 않았습니다.

법규 확인일은 **2026년 11월 11일**이며 외국환거래규정은 **2026년 11월 2일 시행본**을 반영했습니다. 공개 구샘플의 외화차입 금액, 부동산 사후보고 등은 현행 기준과 구별했습니다. 2026년 12월 3일 시행 예정 조문은 적용하지 않았습니다. [제57회 공식 공지](https://www.kbi.or.kr/platformWeb/Customer.do?cmd=openPage&pageName=customerNoticeView&seq=82111)는 시험일인 11월 21일까지 시행된 개정내용도 시험범위에 포함한다고 안내합니다. 시험 전 추가 공지·교재 정오표도 확인해야 합니다. 계산의 환율·금리는 가상 조건입니다.

각 해설에 근거 링크가 있고 자료 메뉴에서 교재 목차와 출처를 확인할 수 있습니다.

## 2026.11.11 최종 검수

기존 300문항 전부를 공식 교재 24장 목차, 공개 샘플 15문항, 현행 법령, 공식 정오표·교육자료와 대조했습니다. 정답을 O↔X로 바꿀 확정 오류는 발견하지 못했지만, **33문항의 전제조건·해설·출처를 수정·통합**했습니다. 반복 쟁점 **24문항을 신규 핵심 24문항으로 교체**하여 총 300문항(150/90/60)은 유지했습니다.

- 법규: 해외법인 대여의 해외직접투자 관계 요건, 외화차입 누적 기준, 해외부동산 사후보고 대상, 보고·신고 및 판정·허가 용어를 명확히 했습니다.
- 거래: 고객·은행의 환율 관점, 결제위험의 지급·수취 통화, 미달환 표현을 다듬고 직접 확인할 수 있는 공식 출처를 보완했습니다.
- 리스크: 옵션의 달러당 단위·프리미엄 외 비용 조건, 스왑의 현금흐름·계약조건을 명확히 했습니다.
- 추가 핵심: 외환매입 확인·통보, 소액송금 한도, 상호계산·기간 초과 지급, 투자 취득보고·외투기업 등록·방산 허가·원산지, MX·ISO 20022·외화예금 계정, 옵션전략 4개·O/N·T/N입니다.

자료 메뉴에서 수정·보강한 **57문항을 모아 복습**할 수 있습니다. 정오표는 [거래실무 2026](https://www.kbi.or.kr/platformWeb/Book.do?cmd=openPage&pageName=bookModifyAllDetail&bltnId=1&oText=56757)과 [환리스크관리 전정5판](https://www.kbi.or.kr/platformWeb/Book.do?cmd=openPage&pageName=bookModifyAllDetail&bltnId=1&oText=56741)을 확인했습니다.

검수 한계: 교재 본문 전체나 실제 회차별 기출 원문을 확보한 검수는 아닙니다. 은행 고유 계정과목·실무 분개·손익계정의 세부 사례, 위험관리 실행 절차·권고안 등은 교재를 추가로 확인해야 합니다. 300문항이 모든 세부 내용을 망라하거나 출제를 보장하지 않습니다.

## 학습기록

기록은 현재 기기·브라우저의 localStorage에 저장되며 서버로 전송하지 않습니다. 다른 기기·브라우저로 이동하려면 자료 메뉴에서 JSON 백업을 사용하세요. 가져오기는 문항별 더 최근 기록을 합칩니다.

기존 버전의 답안·오답·★·풀이 횟수는 유지합니다. 중복 쟁점인 기존 ID 71과 이번 검수에서 교체한 24문항의 과거 기록은 백업에서 보존합니다. 새 문제에는 새 ID를 부여하여 예전 답안이 자동 적용되지 않게 했으며 현재 진도·오답은 활성 300문항만 집계합니다. 새 목차 전환 시 이전 묶음 대신 아직 풀지 않은 문제부터 시작합니다. 새 버전에서는 목차·오답으로 이동해도 순서 학습의 이어풀기 위치를 따로 보존합니다.

## 기술·검증

별도 빌드가 없는 HTML/CSS/JavaScript 사이트입니다. GitHub Pages로 배포하며 서비스워커는 온라인 우선, 연결 실패 시 준비된 캐시를 사용합니다. 전체 기록 저장 키는 기존 `cfes1-ox-study-v1`을 유지합니다.

검증 항목: 300문항 고유 ID·형식·정답·출처, 24단원 중복 없는 배치, 검수 전 300문항의 검토 이력·수정·교체 및 기록 호환, 전체 과정 300문항 진행, 단원·오답을 거친 이어풀기, 잘못된 기록 정규화, 390px·320px 모바일 배치와 O/X 해설 동작.

공개 파일: `index.html`, `app.js`, `questions.js`, `style.css`, `sw.js`, `icon.svg`, `manifest.webmanifest`, `README.md`. 작업용 `tmp/`와 수집한 원본 자료는 배포하지 않습니다.
