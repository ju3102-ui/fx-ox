# 외환 한 시간

외환전문역 1종을 준비하는 모바일 O/X 학습 페이지입니다. **공식 샘플 연계 핵심 67문항 + 새 예상문제 80문항 + 기본개념 보충 53문항 = 전체 200문항**과 해설을 제공합니다.

전체 문항은 외환관리실무 100문항, 외국환거래실무 60문항, 환리스크관리 40문항입니다. 핵심 67문항은 그대로 유지하고, 예상문제를 각각 46·19·15개 추가했습니다. 법규 사례, 해외예금·보증·부동산 임차, 송금 수수료·환율 계산, 결제위험, 선물·옵션 손익을 보강했습니다.

- 과목별 전체·핵심·예상문제 선택 풀이, 공식 샘플 1~15번과의 연결표
- 2026년 11월 21일 시험을 위한 하루 1시간 학습표: 첫 8일 200문항, 이후 핵심 혼합·오답 복습
- 즉시 정답·해설·암기문장·출처 확인
- 오답과 헷갈린 문제 복습, 이어풀기
- 브라우저에 학습기록 저장, JSON 백업·복원
- 반응형 화면과 기본 오프라인 캐시

## 자료 성격

실제 회차별 기출 원문이 아닙니다. 검증한 원자료는 한국금융연수원 공식 샘플 15문항이며, 회차별 실제 기출 원문으로 확인한 자료는 없습니다. 핵심에는 샘플 번호와 선지 쟁점·현행법규 반영·연계 응용을 표시하고 추가 80문항에는 예상문제임을 표시합니다. 예상문제는 공식 법규·교육자료로 새로 작성한 연습문제로 출제 보장이나 출제빈도 분석을 뜻하지 않습니다. 공식 PDF 원문은 재게시하지 않습니다. 문항별 근거와 연결표는 `questions.js` 및 화면에서 확인할 수 있습니다.

법규 확인일: 2026-11-11. 외국환거래규정은 2026-11-02 시행본을 확인했습니다. 해당 시험의 교재·정오표 적용 기준일이 현행 규정과 같은지는 별도 확인이 필요합니다. 이 자료는 시험 전 범위를 대체하지 않으며 합격을 보장하지 않습니다.

## 실행과 배포

빌드 없이 정적 파일을 서비스합니다. 저장소 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하면 GitHub Pages로 배포할 수 있습니다. 하위 경로에서도 동작하도록 모든 내부 경로는 상대경로입니다.

로컬 미리보기: `python3 -m http.server 8765` 실행 후 `http://localhost:8765`로 접속합니다.

학습기록은 기기·브라우저별 localStorage에만 저장됩니다. 기존 1~120번 문항과 기록 식별자를 유지했습니다. 서버 업로드, 분석 도구, 외부 폰트, 로그인 기능은 없습니다. 버전을 바꿀 때 `sw.js`의 캐시 키와 HTML의 자산 버전도 함께 갱신하세요.
