# 외환 한 시간

외환전문역 1종을 준비하는 모바일 O/X 학습 페이지입니다. 외환관리실무 50문항, 외국환거래실무 30문항, 환리스크관리 20문항과 해설을 포함합니다.

- 과목별 풀이와 2026년 11월 21일 시험을 위한 10일 학습표
- 즉시 정답·해설·암기문장·출처 확인
- 오답과 헷갈린 문제 복습, 이어풀기
- 브라우저에 학습기록 저장, JSON 백업·복원
- 반응형 화면과 기본 오프라인 캐시

## 자료 성격

실제 회차별 기출 원문이 아닙니다. 한국금융연수원 공식 샘플 15문항의 주제와 공식 법령·교육자료를 참고하여 새로 만든 연습문제입니다. 공식 PDF 원문은 재게시하지 않습니다. 문항별 근거는 `questions.js`와 화면의 해설에 표시했습니다.

법규 확인일: 2026-11-11. 외국환거래규정은 2026-11-02 시행본을 확인했습니다. 해당 시험의 교재·정오표 적용 기준일이 현행 규정과 같은지는 별도 확인이 필요합니다. 이 자료는 시험 전 범위를 대체하지 않으며 합격을 보장하지 않습니다.

## 실행과 배포

빌드 없이 정적 파일을 서비스합니다. 저장소 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하면 GitHub Pages로 배포할 수 있습니다. 하위 경로에서도 동작하도록 모든 내부 경로는 상대경로입니다.

로컬 미리보기: `python3 -m http.server 8765` 실행 후 `http://localhost:8765`로 접속합니다.

학습기록은 기기·브라우저별 localStorage에만 저장됩니다. 서버 업로드, 분석 도구, 외부 폰트, 로그인 기능은 없습니다. 버전을 바꿀 때 `sw.js`의 캐시 키도 갱신하세요.
